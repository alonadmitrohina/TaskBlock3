# Завдання Блоку 3: Сучасний Frontend

Сутність Song (основна) - відноситься як many-to-one до Сутності Playlist.

Перша сторінка зі списком пісень - /songs:
- Кожна пісня відображає назву та виконавця;
- При наведенні курсору мишки на пісню праворуч з'являється кнопка-іконка "Видалення" (Урна), при натисканні на яку відкривається діалогове вікно з підтвердженням видалення пісні;
- При натисканні на пісню - перехід до детальної інформації;
- Внизу є кнопка "Додати пісню" та реалізована пагінація;
- Список пісень можна відфільтрувати за виконавцем, роком випуску та плейлістом;
- При перезавантаженні сторінки застосований фільтр та пагінація не скидаються.


Друга сторінка із детальною інформацією пісні - /song/id:
- Відображає детальну інформацію пісні у режимах перегляду (mode="view") та редагування, що розділений на два окремих режими для редагування та створення відповідно (mode="edit", mode="create");
- Параметр mode для режиму передається через SearchParams;
- Для редагування та додавання є валідація наявності полів та окрема валідація для року випуску (1500 < рік < наш час);
- При скасування редагування поля не оновлюються.

Для імітації роботи БЕ створено songStorage.js та playlistsStorage.js, дані беруться з файлів songsMockData.js та playlistsMockData.js відповідно. 
До reducer та actions додано song.js та playlists.js. Для зручності та правильності архітектури додано багато компонентів (більшість із них починається із Song).
